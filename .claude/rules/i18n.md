# Internacionalização (@nuxtjs/i18n)

- **O site é SEMPRE bilíngue.** Nada visível existe em um idioma só — nem temporariamente.
  Toda alteração de texto mexe em `pt-BR.json` **e** `en.json` juntos. Não adicione nem
  remova locales.
- Locales: `pt-BR` (padrão, sem prefixo) e `en` (prefixo `/en`). Estratégia
  `prefix_except_default`. Arquivos em `i18n/locales/pt-BR.json` e `i18n/locales/en.json`
  (lazy load).
- **Todo** texto visível (inclusive `alt`, `aria-label`, `title`, meta SEO, mensagens de erro)
  vem do i18n. Zero texto hardcoded em `.vue`.
- Chaves em inglês, `camelCase`, agrupadas por área: `nav.blog`, `home.hero.title`,
  `blog.readingTime`, `seo.home.description`, `common.backToTop`.
- Os dois arquivos JSON têm **exatamente as mesmas chaves**, na mesma ordem. Ao adicionar uma
  chave em um, adicione no outro na mesma alteração.
- **Tipagem e verificação de chaves**:
  - `pt-BR.json` é a fonte dos tipos (`app/types/i18n.d.ts` → `DefineLocaleMessage` e o tipo
    global `MessageKey`).
  - O `t()` do vue-i18n aceita qualquer string (só dá autocomplete), então chaves literais
    são verificadas pelo ESLint (`@intlify/vue-i18n/no-missing-keys`).
  - **Nunca monte chave com template string** (`` t(`theme.${x}`) `` ✗). Para chave variável,
    use um mapa tipado — assim o compilador valida:
    ```ts
    const LABEL_KEYS = {
      light: 'theme.light',
      dark: 'theme.dark',
    } as const satisfies Record<Theme, MessageKey>
    t(LABEL_KEYS[theme])
    ```
  - Em dados (ex.: itens de menu), tipar como `labelKey: MessageKey`.
- Pluralização e interpolação com a sintaxe do vue-i18n:
  `"readingTime": "{n} min de leitura"` → `t('blog.readingTime', { n })`.
  Plural: `"posts": "nenhum post | 1 post | {n} posts"` → `t('blog.posts', n)`.
- Datas e números: `useI18n().d()` / `n()` ou `Intl` com o locale atual — nunca formatar à mão.
- Links: `<NuxtLinkLocale>` / `useLocalePath()`. Troca de idioma: `useSwitchLocalePath()`
  (componente `layout/LocaleSwitcher.vue`).
- SEO: `useLocaleHead({ seo: true })` no layout para `lang`, `hreflang`, canonical e
  `og:locale`. A URL base vem de `NUXT_PUBLIC_SITE_URL` no momento do **build** (prerender).
- Locale atual tipado: `import type { Locale } from 'vue-i18n'` (gerado: `'pt-BR' | 'en'`).
  Não redeclare a union.
- Conteúdo longo (posts, projetos) **não** vai no JSON: fica em `content/<locale>/` (ver
  `content.md`).
- Tom: pt-BR natural (não tradução literal); en idiomático. Se não souber traduzir algo com
  confiança, sinalize na resposta em vez de inventar.
